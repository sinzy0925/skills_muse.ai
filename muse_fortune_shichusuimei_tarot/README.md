# muse_fortune_shichusuimei_tarot（四柱推命 × タロット統合鑑定）

四柱推命とタロットを役割分担させて束ねる、統合鑑定のカスタムスキルです。

- **四柱推命** ＝ 土台：生まれ持った傾向・五行バランス・今年の流れ
- **タロット** ＝ 今の答え：目の前の相談に3枚（現状／課題／助言）

鑑定文は決まった7部構成（命式サマリー→傾向→今の運気→タロット→統合メッセージ→行動ヒント→締めの一言）で、口調は「優しく背中を押す」が既定です。

## 使い方

生年月日（分かれば出生時刻）と相談内容を伝えて「占って」と言います。

| 項目 | 必須／任意 |
| --- | --- |
| 生年月日 | 必須 |
| 出生時刻 | 任意（不明なら時柱なしの簡易鑑定） |
| 相談テーマ／質問 | 必須（仕事・恋愛・お金・人間関係、または自由な質問） |
| 鑑定の長さ | 任意（既定は「標準」約1,000字。短め／じっくりも可） |

## 手順

1. **入力の確認**：不足があればまとめて質問（推測で埋めません）
2. **命式の作成**：同梱の計算ヘルパーで年柱・月柱・日柱・時柱、日主、五行バランス、今年の干支を出す。初回は既知の命式サンプル12件で検算し、通らなければ鑑定を始めません
3. **タロットの抽選**：乱数で3枚引く（正位置・逆位置あり）。1つの質問につき1回だけで、引き直しはしません
4. **統合鑑定の作成**：7部構成で、四柱推命とタロットが重なる点・違う点を統合メッセージに束ねます
5. **提示**：長さや口調の調整は文章側で対応します（命式とカードは変わりません）

## 前提

- 命式の計算に Python ライブラリ **sxtwl** を使います（未導入なら `pip install sxtwl`）。計算できない環境では、暗算に切り替えず停止して報告します
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 占いはエンターテインメントとして提示します。健康・法律・お金について断定的な判断はせず、怖がらせる表現は使いません
- 生年月日などの個人情報はその回の鑑定だけに使い、スキルや共有物に保存しません
- 五行バランスは v1 の簡略化として、天干と地支の本気だけで数えます（蔵干は数えません）
- 大運（10年単位の運気）、出生地による真太陽時の補正、相性占いは v1 の範囲外です

## 由来

ユーザーの設計メモ（2026-11-14）をもとに作成。役割分担（四柱推命＝土台、タロット＝今の答え）、計算の検算を必須とすること、大運を v1 に入れないこと、長さと口調の既定は、本人の確認済みの決定です。
