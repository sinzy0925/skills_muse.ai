# muse_skills_space_update（スキル一式アップデーター）

## 何をするスキルか

GitHubで公開しているスキル一式を、最新の状態にまとめて更新するスキルです。初回の導入（ZIPダウンロード＋登録）に対する「更新」担当で、リポジトリ側で新しいスキルが増えたり、既存スキルやランチャー、シミュレーター、常時参照メモが変わったときに、このスキル1つで全部を最新にそろえます。

## 使い方

チャットで「muse_skills_space_update を実行して」と送るだけです。最初に差分の一覧が出るので、確認してから進みます。

## 手順

1. リポジトリのZIPをダウンロードして展開し、今の状態との差分（追加／更新／ローカルのみ）を一覧で見せる
2. リポジトリのスキルを全部、カスタムスキルに登録し直す（ローカルのみのスキルには触らない）
3. スキルランチャーのスペースを最新HTMLと同じ内容に更新する（サイドバー、アイコンはロケット）
4. 住民税非課税シミュレーターのスペースを最新HTMLと同じ内容に更新する（サイドバー、アイコンはノート）
5. 常時参照して欲しいメモ.md を、常時参照するメモに登録し直す
6. 追加・更新の内訳と、メモの件数を報告する

## 前提

- 更新元は公開リポジトリ https://github.com/sinzy0925/skills_muse.ai/archive/refs/heads/main.zip です。このURLは配布元として作者が指定した公開アドレスで、このスキルに含まれる固有のURLはこれだけです
- スペースの作り直しでは、見た目の細部が元と少し違う場合があります（内容の一致が目的です）

## 注意

- ローカルにだけあるスキルやファイルは、このスキルでは削除しません。削除は別の明示の指示があったときだけ行います
- 共有リンクで公開中のスペースは、再共有するまでリンク先が前の版のままです。再共有は本人のOKの後で行います
