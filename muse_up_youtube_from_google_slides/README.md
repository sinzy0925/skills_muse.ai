# muse_up_youtube_from_google_slides（Google Slides → YouTube Uploader）

完成したGoogleスライドを、**Google Vidsでナレーション付き動画にしてYouTubeへアップロードする**カスタムスキルです。

流れ： **Googleスライド → Google Vids（変換＋AIナレーション）→ YouTubeにエクスポート → YouTube Studio（設定）→ 保存**

スライドのスピーカーノートが、そのまま動画のナレーションになります。ユーザーがやるのは、指示とログインと設定の確認だけです。

## 使い方

スライドのURLと一緒に「YouTubeにアップして」と伝えます。使うブラウザ（内蔵ブラウザ／Chrome拡張「muse from meta」）の指定があれば、それも伝えます。

変換の前に、以下の確認を取ります（タイトルと公開範囲が決まるまで変換は始まりません）。

| 項目 | 必須／任意 |
| --- | --- |
| スライドのURL | 必須 |
| タイトル | 既定はスライドのタイトル（勝手に変えません） |
| 公開範囲 | 必須（公開／限定公開／非公開。指定がなければ限定公開を提案） |
| 子ども向けかどうか | 既定は「いいえ、子ども向けではありません」 |
| 説明文（概要欄） | スライドの内容から下書きを作り、提示してから使用 |
| サムネイル | スライドの先頭ページの画像を準備して使用 |

## 手順

1. **準備**：サムネイル用にスライド先頭ページの画像を保存し、スライドの内容から概要欄の下書きを作る
2. **必要事項の確認**：上表の項目をまとめて確認（ここでの確認が、最後の保存の承認になります）
3. **ログイン確認**：使うブラウザが作業用Googleアカウントでログインしているか確認。切れていたら本人がブラウザでログインする
4. **Vidsに変換**：スライドのファイルメニューから「動画に変換」。取り込み画面では「AIナレーション、スクリプト、バックグラウンドミュージック、アニメーションを含める」をOFFにして進む（ナレーションはスピーカーノートから入れるため）
5. **ナレーション挿入**：「ナレーション」→「すべてのシーン」→「すべてのナレーションを挿入」。全シーンに入るまで待つ
6. **YouTubeにエクスポート**：「YouTubeにエクスポート」→完了後に「YouTubeを開く」
7. **Studioで設定して保存**：タイトル・サムネイル・説明文・視聴者設定・公開設定を入れて「保存」。動画URLを確認して報告する

## 前提

- 作業用Googleアカウントでログインできるブラウザ（内蔵ブラウザ、またはChrome拡張「muse from meta」）。ログインは本人がブラウザの中で行います
- スライドのスピーカーノートにナレーション原稿が入っていること
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- パスワードや認証コードをチャットで送る必要はありません。2段階認証はスマホで承認します
- カスタムサムネイルには、チャンネルの電話番号確認が必要です。未確認のチャンネルではサムネイルだけ設定できず、動画は自動生成サムネイルで保存されます（確認は本人の手続きで、済ませれば後から差し替えでき、以降の動画でも使えます）
- 変換とナレーション挿入には時間がかかります
- 設定値（タイトル・公開範囲など）はその回の確認どおりに使い、前回の動画の設定を流用しません

## 由来

ユーザーが2026-11-14に示した、スライドからYouTubeへ公開する標準手順をスキル化したものです。同日にこの手順で実際に1本の動画を公開したときの確認事項（電話番号確認がないとサムネイルが設定できないこと等）も、注意点として含んでいます。

## 使い方シート

同梱の「使い方シート.md」が、使い方の説明の正本です。使い方を聞かれたら、Museはまず一言説明をして、A（説明だけ聞きたい）／B（実際に使う）を尋ねます。Aではシートをそのまま提示し、Bでは必要な確認や準備をしてから、実際に使うものと一緒に説明します。人に渡すときも、シートごと渡してください。
