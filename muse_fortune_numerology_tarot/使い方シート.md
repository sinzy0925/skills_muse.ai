# muse_fortune_numerology_tarot 使い方シート

一言で言うと、生年月日から数秘術で土台を見て、いまの相談にタロットを引いて、2つを束ねた鑑定文を作るスキルです。

## 聞き方に合わせて、説明のしかたが変わります

- **使い方だけ知りたい場合**：このシートで説明します（生年月日は集めず、カードも引きません）
- **実際に使う場合**：入力項目（生年月日・相談内容）を確認してから、その項目がどう使われるかと一緒に説明します

## 事前準備（最初に1回だけ）

- 初回の鑑定の前に、数秘の計算が正しいかを既知のサンプルで自動チェックします（検算）。チェックを通らない場合は、鑑定を始めずにその旨が報告されます
- 準備として何かをインストールしたり、登録したりする必要はありません

## 普段の使い方

1. 生年月日と相談したいことを伝えます（名前も出生時刻も要りません）
2. 不足している項目があれば、まとめて質問されます。推測で埋めることはしません
3. 数秘術の数字が計算されます（ライフパス・バースデー・パーソナルイヤー）
4. タロットが3枚引かれます（現状／課題／助言）。引いたカードは鑑定文に明記されます
5. 2つを束ねた鑑定文が出ます
   - 数字サマリー → 生まれ持った傾向 → 今の運気の流れ → タロット3枚 → 統合メッセージ → 行動ヒント → 締めの一言
   - 長さは「標準」（1,000字前後）が既定です。「短め」「じっくり」も選べます

## 注意点

- 生年月日だけで占えます。名前に由来する数字はこの版では使いません
- 数字の計算では、11と22は「マスターナンバー」としてそのまま読まれます（2や4に丸めません）
- タロットは1つの質問につき1回だけ引きます。引き直しはしません（別の質問なら、新しい鑑定として引き直せます）
- 占いはエンターテインメントです。健康・法律・お金について断定的な判断はしませんし、怖がらせる言い方もしません
- 生年月日などの個人情報は、その回の鑑定だけに使います。スキルや共有資料に保存されることはありません
- パーソナルイヤー（今年の数字）は、1月から12月の暦年で数える約束になっています
