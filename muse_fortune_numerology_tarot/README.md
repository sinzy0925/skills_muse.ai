# muse_fortune_numerology_tarot（数秘術 × タロット統合鑑定）

数秘術とタロットを役割分担させて束ねる、統合鑑定のカスタムスキルです。

- **数秘術** ＝ 土台：ライフパス（人生のテーマ）、バースデー（生まれ持った才能）、パーソナルイヤー（今年のテーマ）
- **タロット** ＝ 今の答え：目の前の相談に3枚（現状／課題／助言）

鑑定文は決まった7部構成（数字サマリー→傾向→今の運気→タロット→統合メッセージ→行動ヒント→締めの一言）で、口調は「優しく背中を押す」が既定です。姉妹スキル `muse_fortune_shichusuimei_tarot`（四柱推命 × タロット）、`muse_fortune_kyusei_runes`（九星気学 × ルーン）と同じ設計で、こちらは**生年月日だけで占える**のが特徴です（名前も出生時刻も不要）。

## 使い方

生年月日と相談内容を伝えて「占って」と言います。

| 項目 | 必須／任意 |
| --- | --- |
| 生年月日 | 必須 |
| 相談テーマ／質問 | 必須（仕事・恋愛・お金・人間関係、または自由な質問） |
| 鑑定の長さ | 任意（既定は「標準」約1,000字。短め／じっくりも可） |

## 手順

1. **入力の確認**：不足があればまとめて質問（推測で埋めません）
2. **数字の計算**：同梱の計算ヘルパーでライフパス・バースデー・パーソナルイヤーを出す。初回は既知のサンプル（ライフパス5件・マスターナンバー含む、バースデー6件、パーソナルイヤー3件）とタロット78枚の整合性で検算し、通らなければ鑑定を始めません
3. **タロットの抽選**：乱数で3枚引く（正位置・逆位置あり）。1つの質問につき1回だけで、引き直しはしません
4. **統合鑑定の作成**：7部構成で、数秘術とタロットが重なる点・違う点を統合メッセージに束ねます
5. **提示**：長さや口調の調整は文章側で対応します（数字とカードは変わりません）

## 前提

- 計算は純粋な算術なので、外部ライブラリは不要です。それでも暗算には切り替えず、必ずヘルパーの出力を使います
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 占いはエンターテインメントとして提示します。健康・法律・お金について断定的な判断はせず、怖がらせる表現は使いません
- 生年月日などの個人情報はその回の鑑定だけに使い、スキルや共有物に保存しません
- v1 の約束：数字は1〜9に丸めますが、**11と22はマスターナンバーとして残します**。パーソナルイヤーは暦年ベース（1月〜12月）です
- 名前に由来する数字（デスティニー、ソウル、パーソナリティ）は v1 の範囲外です。使うのは誕生日の数字だけです

## 由来

ユーザーの合体占いの設計（2026-11-17）をもとに作成。役割分担（数秘術＝土台、タロット＝今の答え）、計算の検算を必須とすること、誕生日の数字だけを使うこと、長さと口調の既定は、本人の確認済みの決定です。
