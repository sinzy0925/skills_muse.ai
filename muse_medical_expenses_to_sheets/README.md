# muse_medical_expenses_to_sheets（医療費をスプレッドシート台帳へ）

## 何をするスキルか

医療費控除のために、Googleドライブの「医療費整理_実行前」フォルダに入れた病院・薬局の領収書（PDF・画像）を読み取り、通院にかかった交通費のメモと合わせて、Googleスプレッドシートの医療費台帳に整理するスキルです。処理済みのファイルは「医療費整理_実行後」フォルダへ移します。

流れは「接続確認 → 領収書の読み取りと交通費メモの取り込み → 重複統合・見本除外 → 台帳へ追記 → 読み戻して検証 → 要確認点を報告 → 実行後フォルダへ移動 → 移動結果を検証」です。申告時期には、台帳から医療費控除の明細書に転記できる形（受診した人ごと・病院ごとの集計）も出せます。

## 使い方

チャットで「muse_medical_expenses_to_sheets を使って」と呼び出すか、「実行前に領収書を入れたので整理して」のように指示します。

交通費は領収書がないことが多いので、チャットの一言メモでも記録できます（下記の項目が揃っていること）。例：「今日、○○病院、電車で美原駅→なんば駅、往復640円」

同梱の「使い方シート.md」が、使い方の説明の正本です。使い方を聞かれたら、Museはまず一言説明をして、A（説明だけ聞きたい）／B（実際に使う）を尋ねます。Aではシートをそのまま提示し、BではGoogleドライブとスプレッドシートに接続してから、実際に使うURL3つと一緒に説明します。人に渡すときも、シートごと渡してください。

## 事前に必要なもの

- GoogleドライブとGoogleスプレッドシートの接続（未接続の場合、スキルが接続リンクを案内します）
- ドライブのフォルダ「医療費整理_実行前」「医療費整理_実行後」（なければ初回に作成します）
- 台帳のスプレッドシート（なければ初回に下記の形式で作成します）

このスキル自体には、フォルダID・スプレッドシートID・URL・個人情報を一切書いていません。すべて名前で探すので、そのまま他人に共有できます。実際に解決したIDは、使う人それぞれの記録側（メモリなど）に保持してください。

## 台帳の形式

シートは「医療費一覧」「通院交通費メモ」「集計」の3枚です。

「医療費一覧」は11項目：
No. / 日付 / 受診した人 / 病院・薬局 / 区分（診療・治療、医薬品、交通費、その他）/ 内容 / 金額 / 補填される金額 / 差引額（自動計算）/ 証憑・メモ / 備考・要確認

「通院交通費メモ」は、領収書のない交通費の記録用です：
日付 / 受診した人 / 病院 / 交通手段 / 出発駅・バス停 / 到着駅・バス停 / 片道・往復 / 金額 / メモ / 反映

「集計」には受診した人別・区分別・月別の合計と、控除の目安額までの残り、★印商品（セルフメディケーション対象）の別枠集計を用意します。

## 注意

- 読み取れない文字や金額は推測しません。受診した人が領収書から分からない場合も、推測せず「要確認」にします
- 同じ領収書のPDFと写真は重複として1件に統合し、領収書の見本・テンプレート画像は台帳に入れません
- タクシー代は、公共交通機関を使えなかった理由のメモがある場合だけ対象候補にし、必ず「要確認（タクシー）」を付けます。自家用車のガソリン代・駐車場代は対象外として入れません
- ★印の医薬品はセルフメディケーション税制の対象候補です。医療費控除とは併用できないため、別枠で集計し、二重に数えません
- 保険金や高額療養費などの補填は、金額が分かり次第「補填される金額」に記入して差し引きます（最初は空欄で構いません）
- 対象かどうか際どいもの（人間ドック、予防接種など）は判断せず「要確認」にします。税務の判断はこのスキルでは行いません
- 領収書の紙の原本は、申告後も5年間、自宅で保管が必要です。ドライブのスキャンは整理用で、原本の代わりにはなりません
- ファイルの移動は、台帳への記入と読み戻し確認が終わってから行い、移動後に両フォルダを検証します
