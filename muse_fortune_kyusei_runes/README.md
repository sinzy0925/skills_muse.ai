# muse_fortune_kyusei_runes（九星気学 × ルーン統合鑑定）

九星気学とルーンを役割分担させて束ねる、統合鑑定のカスタムスキルです。

- **九星気学** ＝ 土台：本命星・月命星から生まれ持った傾向と、今年の流れ
- **ルーン** ＝ 今の答え：目の前の相談に3つ（現状／課題／助言）

鑑定文は決まった7部構成（命盤サマリー→傾向→今の運気→ルーン→統合メッセージ→行動ヒント→締めの一言）で、口調は「優しく背中を押す」が既定です。姉妹スキル `muse_fortune_shichusuimei_tarot`（四柱推命 × タロット）と同じ設計で、こちらは**生年月日だけで占える**のが特徴です（出生時刻は不要）。

## 使い方

生年月日と相談内容を伝えて「占って」と言います。

| 項目 | 必須／任意 |
| --- | --- |
| 生年月日 | 必須 |
| 相談テーマ／質問 | 必須（仕事・恋愛・お金・人間関係、または自由な質問） |
| 鑑定の長さ | 任意（既定は「標準」約1,000字。短め／じっくりも可） |

## 手順

1. **入力の確認**：不足があればまとめて質問（推測で埋めません）
2. **命盤の作成**：同梱の計算ヘルパーで本命星・月命星・今年の九星を出す。初回は既知のサンプル（本命星7件・月命星4件、立春の境界を含む）とルーン24種の整合性で検算し、通らなければ鑑定を始めません
3. **ルーンの抽選**：エルダー・フサルク24種から乱数で3つ引く（正位置・逆位置あり。形が対称な8種には逆位置がありません）。1つの質問につき1回だけで、引き直しはしません
4. **統合鑑定の作成**：7部構成で、九星気学とルーンが重なる点・違う点を統合メッセージに束ねます
5. **提示**：長さや口調の調整は文章側で対応します（命盤とルーンは変わりません）

## 前提

- 年と月の境目（立春・節入り）の判定に Python ライブラリ **sxtwl** を使います（未導入なら `pip install sxtwl`）。計算できない環境では、暗算に切り替えず停止して報告します
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 占いはエンターテインメントとして提示します。健康・法律・お金について断定的な判断はせず、怖がらせる表現は使いません
- 生年月日などの個人情報はその回の鑑定だけに使い、スキルや共有物に保存しません
- 月命星は v1 の約束として「内面・表に出にくい傾向」として読みます
- 方位（吉方位、日盤・月盤）は v1 の範囲外です。聞かれたら、扱っていない旨を伝えます

## 由来

ユーザーの合体占いの設計（2026-11-17）をもとに作成。役割分担（九星気学＝土台、ルーン＝今の答え）、計算の検算を必須とすること、方位を v1 に入れないこと、手相（写真が必要）は合体占いの対象から外すこと、長さと口調の既定は、本人の確認済みの決定です。
