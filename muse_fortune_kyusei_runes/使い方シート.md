# muse_fortune_kyusei_runes 使い方シート

一言で言うと、生年月日から九星気学で土台を見て、いまの相談にルーンを引いて、2つを束ねた鑑定文を作るスキルです。

## 聞き方に合わせて、説明のしかたが変わります

- **使い方だけ知りたい場合**：このシートで説明します（生年月日は集めず、ルーンも引きません）
- **実際に使う場合**：入力項目（生年月日・相談内容）を確認してから、その項目がどう使われるかと一緒に説明します

## 事前準備（最初に1回だけ）

- 初回の鑑定の前に、九星の計算が正しいかを既知のサンプルで自動チェックします（検算）。チェックを通らない場合は、鑑定を始めずにその旨が報告されます
- 準備として何かをインストールしたり、登録したりする必要はありません

## 普段の使い方

1. 生年月日と相談したいことを伝えます（出生時刻は要りません）
2. 不足している項目があれば、まとめて質問されます。推測で埋めることはしません
3. 九星気学の命盤が作られます（本命星・月命星・今年の九星）
4. ルーンが3つ引かれます（現状／課題／助言）。引いたルーンは鑑定文に明記されます
5. 2つを束ねた鑑定文が出ます
   - 命盤サマリー → 生まれ持った傾向 → 今の運気の流れ → ルーン3つ → 統合メッセージ → 行動ヒント → 締めの一言
   - 長さは「標準」（1,000字前後）が既定です。「短め」「じっくり」も選べます

## 注意点

- 生年月日だけで占えます。出生時刻や出生地は要りません
- ルーンは1つの質問につき1回だけ引きます。引き直しはしません（別の質問なら、新しい鑑定として引き直せます）
- ルーンには形が対称で「逆位置がない」ものが8種あります。当たった場合はそのまま読まれます
- 占いはエンターテインメントです。健康・法律・お金について断定的な判断はしませんし、怖がらせる言い方もしません
- 生年月日などの個人情報は、その回の鑑定だけに使います。スキルや共有資料に保存されることはありません
- 方位（吉方位など）は、この版では扱いません。本命星・月命星と今年の流れまでが範囲です
