# muse_make_slides_without_narration_from_screenshots（スクショからプレゼン資料作成・ノート無し）

手順のスクリーンショット一式を、**プレゼン資料として完成したGoogleスライド**にするカスタムスキルです。

特徴は3つです。

- **スピーカーノートは無し**。スライドだけで内容が完結します
- 各ページでやる作業は、スクショの下に**大きめの太字**で書きます。発表の場で、観客がスライドだけ見て手順を追えます
- スクショ画像は**元のまま**貼り、個人情報のマスクとクリック場所の注釈（赤い楕円＋番号）は**スライド上の図形**で載せるので、後から自分で微調整できます

ナレーション付きの姉妹スキル `muse_make_slides_with_narration_from_screenshots_to_youtube`（YouTube動画向け）とは、ここが違います。プレゼン用ならこちら、動画用ならあちらです。

## 使い方

スクショを送って、「muse_make_slides_without_narration_from_screenshots を使って」と伝えます。あわせて一言メモがあると精度が上がります。

- 何の写真か（例：PCのスクショ）
- 目的は何か（例：Googleアカウントを作成したい人向けの手順にしたい）
- 強調したい点（例：クリックする場所と順番が分かるようにしたい）

メモが無い場合は、最初にこの3点を聞きます。

## 手順

1. **構成案の提示**：表紙＋ステップごとのスライド＋まとめ、の構成を先に出し、OKをもらってから作ります
2. **座標の特定と事前確認**：マスクと注釈の位置を特定し、下書きプレビューで全枚目視確認します（マスク漏れを重点確認）
3. **スライド化**：元の画像を貼り、その上にマスク図形・楕円・番号バッジを載せ、大きめの作業指示文を入れてGoogleスライドに投入
4. **確認と報告**：読み戻して枚数・画像・図形を確認し、ノートが空であることも確かめて、URLを報告します

## 前提

- Google Drive／Google Slidesコネクタの接続（スライドの投入に使用）
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 元の画像ファイルは編集しません。注釈はすべてスライド上の図形です
- 実名・メールアドレスなどは、原則マスクします（範囲はユーザーと確認）
- 修正でデッキ全体を差し替えると、ユーザーが手作業で調整した図形も上書きされます。その場合は事前に伝えます
- 初回の運用：2026-11-08、Chromeプロファイル追加ガイドのプレゼン版（スクショ7枚→全9枚）
