# muse_check_resident_tax_simulation（住民税シミュレーター結果チェッカー）

## 何をするスキルか

スペース「住民税非課税シミュレーター」で判定した結果を、チャットに貼ってもらって詳しく確認するスキルです。

シミュレーターは計算する係、このスキルは検算と解釈をする係です。貼られた入力と結果を読み直し、決め手になる数字を独立に計算し直し、見落としがないかチェックして、年金・税金の最新情報と突き合わせてから、レポートを返します。

## 使い方

1. スペース「住民税非課税シミュレーター」で判定する
2. 結果の下にある「結果をコピー（AI確認用）」ボタンを押す
3. コピーされた文章を、そのままチャットに貼って送る（先頭の一文が、このスキルを呼び出す指示になっています）

## 手順

1. 貼られた内容を表に整理して見せる（入力ミスに気づけるように）
2. 決め手の数字を検算する（雑所得、合計所得金額、級地と人数から決まる非課税限度額、特例135万円の当てはめ）。シミュレーターの結果と違えば、どの数字がどう違うかを示す
3. 見落としをチェックする（配偶者と世帯の判定、企業年金・iDeCoなどの合算漏れ、その他の所得、障害年金・遺族年金の扱い、障害者控除対象者認定書の区分、級地、非課税でも申告が要る場合）
4. 最新情報をWebで確認する（年金額の改定、控除や限度額の制度変更）。公式の出典と確認日を付け、シミュレーターの前提（令和8年度）との差分を出す
5. レポートを返す（判定の要約／検算の結果／見落とし・注意点／最新情報との差分／次のアクション）

## 前提

- 入力は、シミュレーターのコピーボタンで作られた文章が標準です。部分的に欠けていても、ある分で確認し、確認できなかった所はその旨を書きます
- シミュレーター自体を開いたり、直したりはしません

## 注意

- これは概算のチェックであり、税務の助言ではありません。最後に必ず「最終判断は市区町村・税務署に確認してください」と添えます
- 数字を推測で埋めることはしません。最新情報で確認できなかった項目は「未確認」と明記します
- 非課税の判定は控除前の合計所得金額で見るため、「控除を増やして非課税にする」ような提案はしません
