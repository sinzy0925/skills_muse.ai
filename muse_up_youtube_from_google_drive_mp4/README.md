# muse_up_youtube_from_google_drive_mp4（Google Drive mp4 → YouTube Uploader）

Googleドライブに置いたmp4を、**自分の端末にダウンロードすることなく**YouTubeへアップロードするカスタムスキルです。

ファイルの流れ： **Googleドライブ → Muse（作業用コピー）→ YouTube Studio（内蔵ブラウザ）→ YouTube**

ユーザーがやるのは、指示とログインと最終確認だけです。

## 使い方

ドライブのファイルへのリンク、またはファイル名と一緒に「YouTubeにアップして」と伝えます。

アップロード前に、以下の確認を取ります（タイトルと公開範囲が決まるまでアップロードは始まりません）。

| 項目 | 必須／任意 |
| --- | --- |
| タイトル | 必須（勝手に決めません。案の提示は可） |
| 公開範囲 | 必須（公開／限定公開／非公開、または予約公開） |
| 投稿先チャンネル | 既定のチャンネル、または指定 |
| 子ども向けかどうか | 必須（YouTubeの視聴者設定） |
| 説明文 | 任意 |
| サムネイル | 任意（ユーザーが用意または承認した画像） |

## 手順

1. **mp4の特定と取得**：リンクまたはファイル名からドライブ内のファイルを特定し、作業用コピーを取得。長さ・形式・サイズを確認（原本は変更・削除しません）
2. **必要事項の確認**：上表の項目をまとめて確認
3. **YouTube Studioを開く**：内蔵ブラウザでStudioを開き、必要ならユーザーが安全な入力でログイン
4. **アップロード**：作業用コピーをアップロードし、完了と処理を待つ
5. **設定と公開**：タイトル・説明文・サムネイル・視聴者設定・公開範囲を入力し、**公開前に最終設定を見せてOKをもらってから**公開
6. **確認と後片付け**：動画URLを確認して報告。作業用コピーの削除はユーザーの希望がある場合のみ

## 前提

- Google Driveコネクタの接続（mp4の取得に使用）
- 内蔵ブラウザでのYouTubeログイン（ドライブ連携とは別物で、初回は両方必要）
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- パスワードや認証コードをチャットで送る必要はありません。ログインは内蔵ブラウザでユーザーが自分で行い、2段階認証はスマホで承認します
- 大きなファイルはブラウザ経由だと時間がかかったり、途中で失敗したりする場合があります（その場合は代替案を提示します）
- 設定値（タイトル・公開範囲・チャンネル）はユーザーの確認どおりに使い、前回の動画の設定を流用しません
