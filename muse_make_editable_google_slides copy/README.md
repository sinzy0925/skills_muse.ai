# muse_make_editable_google_slides（YouTube Video Slide Maker）

殴り書きメモや会話ログから、YouTube動画の素材一式（構成・スライド本文・ナレーション原稿・画像・タイトル案／概要欄案）を作り、Googleスライドへは**見出し・本文・表を画像化せず、編集可能なテキストのまま**投入するカスタムスキルです。

## できること

- メモや箇条書きから、動画1本分のスライド構成・本文・ナレーション原稿を作成
- 会話ログ（Cursorのjsonl形式など）を先に要約し、動画化できる部分だけを抽出
- 統一した画風でサムネイルとスライド画像を生成（ユーザーが用意した画像の配置も可能）
- 編集可能なテキストのままGoogleスライドへ投入し、投入後にページ数とテキストを読み戻して確認

## 入力

以下のどちらかから始めます。

- 殴り書きメモ・箇条書き（貼り付けまたはファイル添付）
- 会話ログファイル（先に要約して確認を取ってから進みます）

作業前に、**形式・長さ・画像スタイル・チェックポイント**を確認します（未指定の項目は、言語＝日本語、画面比＝16:9、トーン＝カジュアルで分かりやすく、対象＝一般の初心者、で進みます）。

| 項目 | 選択肢 |
| --- | --- |
| 形式 | プレゼンテーション形式／マンガ形式 |
| 画像生成 | Muse（標準の画像生成）／Gemini（内蔵ブラウザ経由） |
| チェックポイント | A：構成まで／B：本文まで／C：ナレーションまで／D：全部自動 |

## 成果物

動画ごとに `~/workspace/youtube-videos/<slug>/` フォルダが作られます。

| ファイル | 内容 |
| --- | --- |
| brief.md | 形式・枚数・画像スタイルなどの確定パラメータ |
| source-notes.md | 会話ログの要約（ログ入力のとき） |
| structure.md | スライド構成（サムネイル＋本体） |
| content.md | 各スライドのタイトル・本文・画像指示 |
| narrations.md | ナレーション原稿 |
| images/ | サムネイルとスライド画像 |
| upload.json | 素材一式の索引（画像の実在チェック済み） |
| youtube-meta.md | タイトル案3つ・概要欄案・タグ案 |
| manual-steps.md | ユーザーが行う手動ステップの手順書 |
| slides-result.json | 投入先GoogleスライドのURL |

## 画像生成をGeminiにする場合

事前確認で画像生成に「Gemini」を選んだときだけ、画像は内蔵ブラウザのGeminiで生成します。

- Geminiを使うのは、**内蔵ブラウザがGoogleにログインしている場合に限ります**
- 未ログインの場合は、先にGoogleのログイン画面を開き、ユーザーが自分でサインインします（パスワードや認証コードをチャットで送る必要はありません）。ログイン状態を確認してから生成を始めます
- ログインをやめた・できない場合はGemini生成には進まず、Museの画像生成に切り替えるか中断するかを確認します
- 生成は1枚につき新規チャットでプロンプトを送り、フルサイズでダウンロードして、標準のファイル名（thumbnail.png、slide-01.png…）で images/ に配置します

## 前提

- Google SlidesコネクタとGoogle Driveコネクタの接続（Googleスライド投入時に使用）
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 手動ステップ（ユーザーが行う部分）

Googleスライド投入までがスキルの範囲です。以下は手順書（manual-steps.md）として渡すので、ユーザーが自分で行います。

1. Googleスライドで内容を確認
2. Google Vidsへ変換し、ナレーション原稿どおりに音声を設定
3. YouTubeへ公開（タイトル・概要欄・タグはyoutube-meta.mdから）

## 注意

- 製品名・サービス名などの固有名詞は、**ユーザーの書いた表記をそのまま保持**します（例：ユーザーが「Muse」と書けば、どこでも「Muse」。似た名前への置き換えや「修正」はしません）
- 会話ログに含まれるトークン・パスワード・個人情報は要約や成果物に含めません
- デザイン再現を優先して画像化したスライドにするのは、ユーザーが明示した場合のみ（その場合はテキストが編集できなくなる旨を事前に伝えます）
