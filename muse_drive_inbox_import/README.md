# muse_drive_inbox_import（ドライブ受け取りフォルダ → Muse保管）

Googleドライブの受け取り専用フォルダを「水道管」にして、大きなファイル（主に動画）をClaude側の保管場所へ取り込むカスタムスキルです。

- **Googleドライブ** ＝ 水道管：無料枠は15GBと小さいので、ファイルは1つずつ通すだけ
- **Muse の保管フォルダ** ＝ タンク：取り込んだファイルはここに貯まり、「○○見せて」の一言でチャットに添付して再生できます

ドライブ側のファイルは、Muse が消すことは決してありません。取り込み完了の報告を見てから、使う人が手で消します（手動で確実、が設計の決め事です）。

## 使い方

1. ドライブの「Muse受け取り」フォルダにファイルを入れる（パソコン版ドライブのアプリを入れておくと、普通のフォルダへのドラッグ＆ドロップで済みます）
2. チャットで「取り込んで」と言う
3. Muse が一覧→取得→照合（サイズ、動画なら長さ）→保管メモへの記録→完了報告をします
4. 報告を確認してから、ドライブ側のファイルを手で消す（空きが戻ります）

見るときは「○○見せて」と言うだけです。ファイル名があいまいでも、保管メモから探します。

## 手順（スキル側）

1. **初回セットアップ**（1回だけ）：ドライブ接続の確認、受け取りフォルダ「Muse受け取り」を名前で探す（無ければ作成）、保管フォルダと保管メモの用意
2. **一覧**：受け取りフォルダの中身（名前・サイズ）を先に報告する
3. **取得と照合**：保管フォルダ（`~/workspace/your_files/videos/`）へダウンロードし、サイズ一致を確認。動画は長さも測る。同名ファイルがある場合は上書きせず、サイズが同じなら取り込み済みとして扱い、違うなら確認する
4. **記録と報告**：保管メモ.md に1行ずつ追記し、完了を報告する。ドライブ側は消さない

## 前提

- Googleドライブのコネクターが接続されていること
- 保管先の空き容量に限りがあること（大きなファイルを際限なく貯める用途ではありません）
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- ここでの保管は「コピー」です。専用のバックアップサービスではないので、原本はパソコンにも残してください
- フォルダやファイルは名前で解決します。スキル内に固有のフォルダID・ファイルID・URLは含まれていません
- 取り込みの照合（サイズ不一致など）が通らないファイルは、取り込み完了として報告しません

## 由来

ユーザーの発案（2026-11-15）。「ドライブを水道管にして、Muse をタンクとして使う」方式と、自動化しすぎず「手動で確実」を選んだ判断は本人の決定です。保管フォルダと「見せて」の運用は、同日の会話で実際に試して決まりました。

## 使い方シート

同梱の「使い方シート.md」が、使い方の説明の正本です。使い方を聞かれたら、Museはまず一言説明をして、A（説明だけ聞きたい）／B（実際に使う）を尋ねます。Aではシートをそのまま提示し、Bではドライブ接続の確認と初回セットアップをしてから、実際のフォルダと一緒に説明します。人に渡すときも、シートごと渡してください。
