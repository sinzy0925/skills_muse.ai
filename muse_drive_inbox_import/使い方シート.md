# muse_drive_inbox_import 使い方シート

一言で言うと、Googleドライブの専用フォルダを水道管にして、大きな動画などのファイルをClaude側の保管場所へ取り込むスキルです。

## 聞き方に合わせて、説明のしかたが変わります

- **使い方だけ知りたい場合**：このシートで説明します（ドライブには接続せず、ファイルも取り込みません）
- **実際に使う場合**：Googleドライブの接続を確認し、初回セットアップ（受け取りフォルダの用意）をしてから、実際のフォルダと一緒に説明します

## 事前準備（最初に1回だけ）

- GoogleドライブをClaudeに接続します
- 受け取り専用フォルダ「Muse受け取り」をドライブに用意します（無ければClaudeが作ります）
- パソコンには、パソコン版ドライブのアプリを入れておくと楽です。「Muse受け取り」フォルダが普通のフォルダとして出てくるので、ファイルを放り込むだけでアップロードされます

## 普段の使い方

1. 「Muse受け取り」フォルダにファイルを入れます（大きなファイルはアップロードに時間がかかります。同期が終わってから次へ）
2. チャットで「取り込んで」と言います
3. Claudeが中身の一覧を出してから取り込み、サイズ（動画なら長さも）を照合して、保管メモに記録します
4. 完了報告が来たら、ドライブ側のファイルを手で消します（Claudeはドライブ側を絶対に消しません）
5. 見たいときは「○○見せて」と言います。チャットにファイルが付くので、そのまま再生できます（見ている間、トークンは消費されません）

## 注意点

- ドライブの無料枠は15GBです。1ファイルずつ通して、報告の後に消す、が基本のリズムです
- 報告より先にドライブ側を消さないでください。取り込みに失敗していたときに困ります
- 保管は「コピー」です。専用のバックアップサービスではないので、原本はパソコンにも残してください
- 同じ名前のファイルがある場合、Claudeは勝手に上書きしません（サイズが同じなら取り込み済みとして扱います）
- 保管したファイルの名前は、あとから「○○を△△に変えて」で分かりやすい名前に変えられます
