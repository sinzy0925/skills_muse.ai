# muse_make_slides_with_narration_from_screenshots_to_youtube（スクショから手順スライド作成）

手順のスクリーンショット一式を、**編集できるGoogleスライドの手順資料**にするカスタムスキルです。

特徴は2つです。

- スクショ画像は**元のまま**スライドに貼る。個人情報のマスクと、クリック場所の注釈（赤い楕円＋番号）は、**スライド上の図形**として上に載せるので、後から自分でドラッグして微調整できます
- 各ページのスピーカーノートに、そのページの作業内容を説明する**ナレーション原稿**が入るので、そのままYouTube動画の読み上げに使えます

## 使い方

スクショを送って、「muse_make_slides_with_narration_from_screenshots_to_youtube を使って」と伝えます。あわせて一言メモがあると精度が上がります。

- 何の写真か（例：PCのスクショ）
- 目的は何か（例：Googleアカウントを作成したい人向けの手順にしたい）
- 強調したい点（例：クリックする場所が分かるようにしたい）

メモが無い場合は、最初にこの3点を聞きます。

## 手順

1. **構成案の提示**：表紙＋ステップごとのスライド＋まとめ、の構成を先に出し、OKをもらってから作ります
2. **座標の特定と事前確認**：マスクと注釈の位置を特定し、下書きプレビューで全枚目視確認します（マスク漏れ、特に同じ情報が次の画面にも写っているケースを重点確認）
3. **スライド化**：元の画像を貼り、その上にマスク図形・楕円・番号バッジを載せ、本文とナレーションを入れてGoogleスライドに投入
4. **確認と報告**：読み戻して枚数・画像・図形・ノートを確認し、URLを報告します

## 前提

- Google Drive／Google Slidesコネクタの接続（スライドの投入に使用）
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 元の画像ファイルは編集しません。注釈はすべてスライド上の図形です
- 実名・メールアドレスなどは、原則マスクします（範囲はユーザーと確認）
- 修正でデッキ全体を差し替えると、ユーザーが手作業で調整した図形も上書きされます。その場合は事前に伝えます
- 初回の運用：2026-11-08、Googleアカウント作成ガイド（スクショ8枚→全10枚）
