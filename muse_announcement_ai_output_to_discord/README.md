# muse_announcement_ai_output_to_discord（AIアウトプット雑談会 告知メーカー）

毎週土曜朝8時開催のAIアウトプット雑談会の**告知文を、例文の型どおりに作り、確認後にDiscordへ投稿する**カスタムスキルです。日付は「作成した週の土曜日」に自動で合わせます。投稿は内蔵ブラウザで、ユーザーが本人としてログインした状態で行います。

## できること

- 例文（`references/example-announcement.md`）をもとに、今週の告知文を作成
- 日付を作成した週の土曜日に合わせる（例：水曜に作れば、その週の土曜日の日付）
- 季節の挨拶の段落だけを、その月・季節に合わせて調整
- 確認とOKの後に、指定スレッドへ投稿し、表示まで確認

## 投稿先

| 成果物 | 投稿先 | 形式 |
| --- | --- | --- |
| 告知文 | SHIFT AI オンラインコミュニティ／🧑‍💻サークル内のスレッド『AIアウトプット雑談会』 | 文章のみ・1通で投稿 |

WebhookやBotは使わず、内蔵ブラウザでDiscordにログインした本人のアカウントで投稿します。スレッドのURLはスキルには書かず、使う人の記録側で持ちます。

## 絶対に変えないもの

告知文の「参加はこちらから」のブロックは、一字一句変えずにそのまま使います。

```
参加はこちらから😄
【https://us06web.zoom.us/j/84933352139?pwd=euZBMSSkbyDEhDjtYM38jCcgOn2DAN.1#success】 　
ID: 849 3335 2139 　
パスコード: 343996
```

末尾の「💖改めてご紹介 」の紹介文も、固定文としてそのまま使います。

## 日付のルール

- 月〜金に作成 → その週の土曜日
- 土曜の朝8時の開催前に作成 → その日
- 土曜の開催後・日曜に作成、または「次回分」と言われた場合 → 翌週の土曜日
- 告知文には「M月D日（土）」の形で入れ、季節の挨拶の月も同じ月にします

## 手順

1. **日付の決定**：上のルールで対象の土曜日を決める
2. **告知文の作成**：例文の日付と季節の段落だけを差し替え、他は例文どおりに作る
3. **確認**：日付と文面をユーザーに見せ、OKまたは修正をもらう。OKが出るまで投稿しない
4. **重複チェック**：投稿前にスレッドの末尾を見て、同じ日付の告知が既にあれば投稿せずに伝える
5. **投稿と確認**：『AIアウトプット雑談会』スレッドへ1通で投稿し、末尾に表示されたことを確認して報告する

## 前提

- Discordへのログインはユーザーが内蔵ブラウザで事前に済ませておく（パスワードや認証コードをチャットで送る必要はありません）
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 下書きの確認と本人のOKなしに投稿しません
- ZoomのURL・ID・パスコードは絶対に変えません（数字を打ち直さず、例文からそのままコピーします）
- 例文にない新しい事実や宣伝文句は足しません
- Discordの1通あたりの文字数上限は2,000文字です（例文はその範囲内に収まります）

## 使い方シート

同梱の「使い方シート.md」が、使い方の説明の正本です。使い方を聞かれたら、Museはまず一言説明をして、A（説明だけ聞きたい）／B（実際に使う）を尋ねます。Aではシートをそのまま提示し、Bでは日付を決めて下書きを作りながら説明します。人に渡すときも、シートごと渡してください。
