# muse_up_to_x（Xに投稿するスキル）

## 何をするスキルか

X（旧Twitter）への投稿を、ユーザーのPCのChrome（Muse from Meta拡張機能）経由で行うスキルです。

- 内蔵ブラウザではXにログインできない（ログインがエラーで止まる）ため、投稿には使いません。必ずPCのChromeで、Xにログインできている状態で投稿します。
- 投稿の文章は、必ず事前に全文を見せてユーザーのOKをもらってから投稿します。
- 添付ファイル（画像・動画・GIF）が必要かどうかを、毎回ユーザーに確認します。
- 投稿しただけでは終わらず、実際に表示されたかを確認し、投稿URLを報告します。自分の投稿への返信（コメント欄への続きの掲載）にも対応します。

## 使い方

1. チャットで「muse_up_to_x を使って」と言い、投稿したい内容を伝えます
2. Museが文章の下書きを全文提示します。直したいところを伝えて、最終版にOKを出します
3. 添付ファイルが必要かどうか聞かれるので、「なし」か、付けるファイルを指定します
4. 無料枠の制限（文字数・動画の長さやサイズなど）をMuseが確認します。超える場合は、返信に分けるなどの案が出ます
5. コメント欄に続きを載せる場合は、その返信文も事前に確認します
6. Muse from Meta（PCのChrome）で投稿され、投稿URLが報告されます

## 手順の要点

- 投稿先アカウントは、実行時にPCのChromeでログインしているXアカウントです（スキル内にアカウント名は書きません）。画面で確認し、想定と違うアカウントなら報告します。
- ログインが切れていたら、そこで止まります。ログイン操作はユーザー本人が行います（パスワードやコードをチャットで受け取ることはありません）。
- 送信できたか分からない状態で、同じ内容を再投稿しません。まず実際の状態を確認します。
- 投稿中にX Premium（有料プラン）の案内が出たら、閉じて続けます。登録や課金はしません。

## 前提

- ユーザーのPCのChromeに「Muse from Meta」拡張機能が入っていて、Xにログインできていること（スマホや内蔵ブラウザからは投稿できません）。
- 投稿する文章と添付ファイルは、ユーザーが用意・指定すること。

## 無料アカウントの制限（投稿前に確認するもの）

- 文章：1投稿あたり280文字相当まで（日本語は1文字で2文字分、URLは23文字分として数えます）。超える場合は返信に分割します。
- 動画：140秒以内、512MB以内、MP4形式。
- GIF：Webでは15MB以内（スマホアプリでは5MB以内）。
- 画像：5MB以内。

## 注意

- このスキルに、アカウント名・URL・スケジュールなどの固有情報は含まれていません。
- 投稿は取り消しが効きにくい操作です。必ず事前確認のOKが出てから投稿します。
