# muse_login_google_account（内蔵ブラウザでGoogleにログイン）

## 何をするスキルか

Museの内蔵ブラウザを、指定したGoogleアカウントでログイン済みの状態にするスキルです。
Geminiでの画像生成・文字起こし、YouTube Studio、Googleドライブなど、内蔵ブラウザでGoogleのサービスを使う作業の前段になります。

ログインそのものは、必ず本人が行います。このスキルは「ページを開く → 本人にブラウザを渡す → 終わったら確認する」の流れを決めたものです。

## 使い方

チャットで「muse_login_google_account を使って」と呼び出します。対象のアカウントは、そのときに指定してください（スキル本体にはアカウント名やメールアドレスを書きません）。

## 手順

1. Googleのサービスのページ（GeminiやGoogleアカウントのページ）を内蔵ブラウザで開き、今のログイン状態を見る
2. 指定のアカウントでログイン済みなら、それを報告して終わり
3. 未ログイン（または別のアカウント）なら、ブラウザを本人に渡して、メールアドレス・パスワード・2段階認証を本人に入力してもらう
4. 本人が「終わった」と言ったらページを読み直し、表示されているアカウント名とメールアドレスが指定通りか確認して報告する

## 前提・注意

- パスワードや認証コードを、チャットで送ってもらうことは決してしません。入力は全部、本人がブラウザの中で行います
- 別のアカウントでログイン済みのときは、勝手にログアウトしません。本人に切り替えるかどうかを確認します
- 内蔵ブラウザのログイン状態は、時間が経つと切れていることがあります。過去にログインしたからといって今も有効とは限らないので、Googleのサービスを使う作業の前に、このスキルで状態を確認するのが確実です
- 対象は「既にあるアカウントへのログイン」です。Googleアカウントの新規作成は、このブラウザでは止められることがあるため、このスキルの対象外です
- ログイン時にスマホ側へ確認が出ることがあります。その承認は本人のスマホで行うものです
