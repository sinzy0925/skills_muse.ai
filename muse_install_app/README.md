# muse_install_app（スキル一式インストーラー）

## 何をするスキルか

GitHubで公開しているカスタムスキル一式を、初めての環境にまとめて入れるためのインストーラーです。

利用者の操作は3つだけです。

1. GitHubリポジトリのZIPをダウンロードする
2. ZIPを展開する
3. 展開したフォルダの中の muse_install_app スキルを、自分のClaudeに実行してもらう

あとはスキルが、カスタムスキルの登録・常時参照メモの保存・スペースの作成までを一気に進めます（途中で1回、インストール計画の確認があります）。

- リポジトリ： https://github.com/sinzy0925/skills_muse.ai
- ZIP： https://github.com/sinzy0925/skills_muse.ai/archive/refs/heads/main.zip

## インストールされるもの

- カスタムスキル一式（ZIPに含まれる muse_* フォルダ全部）
- 常時参照して欲しいメモ（ルール集）
- スペース7つ
  - スキルランチャー／住民税非課税シミュレーター／占いランチャー（ZIP内のHTMLから作成）
  - トークンメーター／システムメーター／タスクメーター／スペースランチャー（ZIP内の「再現のための仕様書」から作成）

## 手順（実行するClaude側）

1. 展開フォルダの中身を確認し、インストール計画を利用者に見せてOKをもらう
2. カスタムスキルを登録する（同名がある場合は上書き確認）
3. 常時参照メモを保存する
4. スペースを作成する（HTML／仕様書から）
5. できたもの・できなかったもの・判断が要るものを分けて報告する

詳しい手順は SKILL.md にあります。

## 前提・注意

- 初回インストール専用です。インストール済みの環境を最新にしたい場合は muse_skills_space_update を使ってください。
- スペースの公開共有（公開リンク）はこのスキルでは行いません。
- 素材がZIPに無いものは勝手に作らず、報告して終わります。
- 特定のアカウントや場所に紐づくIDは扱いません。入口は公開リポジトリだけです。
