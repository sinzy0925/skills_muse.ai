# muse_install_app の使い方

一言説明：GitHubのZIPを展開してこのスキルを実行するだけで、カスタムスキル一式・常時参照メモ・スペース一式をまとめてインストールできる初回セットアップ用スキルです。

まず聞きます。どちらの形で使いますか？

- A：説明だけ聞きたい → このシートの提示のみで終わります
- B：実際に使う → 下の流れで、実際にインストールします

## Bの場合の流れ

用意するもの：

- GitHubリポジトリのZIP（ダウンロードと展開が済んでいること）
  - https://github.com/sinzy0925/skills_muse.ai/archive/refs/heads/main.zip

進み方：

1. 展開したフォルダの中身を確認し、インストール計画（スキル・メモ・スペースの一覧）をお見せします
2. OKをいただいてから、カスタムスキルの登録 → 常時参照メモの保存 → スペースの作成、の順に進めます
3. 最後に、入ったもの・入らなかったもの・判断が要るものを分けて報告します

## 注意

- 初回専用です。更新には muse_skills_space_update を使います
- 同名のスキルやスペースが既にある場合は、上書きしてよいか必ず確認します
- スペースの公開リンクは発行しません（共有は持ち主の判断です）
