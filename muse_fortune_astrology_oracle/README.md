# muse_fortune_astrology_oracle（西洋占星術 × オラクルカード統合鑑定）

西洋占星術とオラクルカードを役割分担させて束ねる、統合鑑定のカスタムスキルです。

- **西洋占星術** ＝ 土台：太陽星座（基本の自分）、月星座（感情・素の自分）、上昇宮（外からの見え方）と、現在の木星・土星から見る今年の流れ
- **オラクルカード** ＝ 今の答え：目の前の相談に3枚（現状／課題／助言）。このスキル専用のオリジナル36枚デッキを使います

鑑定文は決まった7部構成（ホロスコープ・サマリー→傾向→今の運気→オラクル→統合メッセージ→行動ヒント→締めの一言）で、口調は「優しく背中を押す」が既定です。姉妹スキル `muse_fortune_shichusuimei_tarot`（四柱推命 × タロット）、`muse_fortune_kyusei_runes`（九星気学 × ルーン）、`muse_fortune_numerology_tarot`（数秘術 × タロット）と同じ設計です。

## 使い方

生年月日（分かれば出生時刻と出生地）と相談内容を伝えて「占って」と言います。

| 項目 | 必須／任意 |
| --- | --- |
| 生年月日 | 必須 |
| 出生時刻 | 任意（不明なら太陽星座のみの簡易鑑定） |
| 出生地 | 任意（都道府県庁所在地の名前、または緯度経度。無いと上昇宮は出しません） |
| 相談テーマ／質問 | 必須（仕事・恋愛・お金・人間関係、または自由な質問） |
| 鑑定の長さ | 任意（既定は「標準」約1,000字。短め／じっくりも可） |

## 手順

1. **入力の確認**：不足があればまとめて質問（推測で埋めません。任意項目は無ければ無いまま進めます）
2. **ホロスコープの作成**：同梱の計算ヘルパーがスイス・エフェメリスで太陽・月・上昇宮と現在の木星・土星の星座を出す。初回は既知のサンプル（太陽星座4件、アインシュタインの出生チャート＝太陽・魚座／月・射手座／上昇宮・蟹座、出生地テーブル、オラクル36枚の整合性）で検算し、通らなければ鑑定を始めません
3. **オラクルの抽選**：オリジナル36枚から乱数で3枚引く（逆位置はありません）。1つの質問につき1回だけで、引き直しはしません
4. **統合鑑定の作成**：7部構成で、西洋占星術とオラクルが重なる点・違う点を統合メッセージに束ねます
5. **提示**：長さや口調の調整は文章側で対応します（チャートとカードは変わりません）

## 前提

- 天体位置の計算に Python ライブラリ **pyswisseph**（スイス・エフェメリス）を使います（未導入なら `pip install pyswisseph`）。内蔵のモシアー暦を使うためデータファイルは不要です。計算できない環境では、カレンダー表の当て推量に切り替えず停止して報告します
- 日本の出生地は、県庁所在地の座標と日本時間で計算します
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 占いはエンターテインメントとして提示します。健康・法律・お金について断定的な判断はせず、怖がらせる表現は使いません
- 生年月日などの個人情報はその回の鑑定だけに使い、スキルや共有物に保存しません
- ハウスと詳しいアスペクトは v1 の範囲外です。扱うのは太陽・月・上昇宮と現在の木星・土星までです
- 「朝」「夜」のような曖昧な出生時刻は、月星座・上昇宮には使わず、時刻不明として扱います

## 由来

ユーザーの合体占いの設計（2026-11-17）をもとに作成。役割分担（西洋占星術＝土台、オラクル＝今の答え）、計算の検算を必須とすること、オラクルはオリジナル36枚とすること、ハウスを v1 に入れないこと、長さと口調の既定は、本人の確認済みの決定です。
