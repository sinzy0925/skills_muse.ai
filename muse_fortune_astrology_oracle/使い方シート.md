# muse_fortune_astrology_oracle 使い方シート

一言で言うと、生まれた日の星の配置から西洋占星術で土台を見て、いまの相談にオラクルカードを引いて、2つを束ねた鑑定文を作るスキルです。

## 聞き方に合わせて、説明のしかたが変わります

- **使い方だけ知りたい場合**：このシートで説明します（生年月日は集めず、カードも引きません）
- **実際に使う場合**：入力項目（生年月日・出生時刻・出生地・相談内容）を確認してから、その項目がどう使われるかと一緒に説明します

## 事前準備（最初に1回だけ）

- 初回の鑑定の前に、星の計算が正しいかを既知のサンプルで自動チェックします（検算）。チェックを通らない場合は、鑑定を始めずにその旨が報告されます
- 準備として何かをインストールしたり、登録したりする必要はありません

## 普段の使い方

1. 生年月日と相談したいことを伝えます（出生時刻と出生地が分かれば、それも伝えます）
2. 不足している項目があれば、まとめて質問されます。推測で埋めることはしません
3. ホロスコープが作られます（太陽星座・月星座・上昇宮と、現在の木星・土星の星座）
4. オラクルカードが3枚引かれます（現状／課題／助言）。引いたカードは鑑定文に明記されます
5. 2つを束ねた鑑定文が出ます
   - ホロスコープ・サマリー → 生まれ持った傾向 → 今の運気の流れ → オラクル3枚 → 統合メッセージ → 行動ヒント → 締めの一言
   - 長さは「標準」（1,000字前後）が既定です。「短め」「じっくり」も選べます

## 注意点

- 出生時刻が分からなくても占えます。その場合は太陽星座のみの簡易鑑定になり、鑑定文にもその旨が書かれます
- 出生地が分からない場合は、上昇宮（アセンダント）は出ません
- オラクルカードはこのスキル専用のオリジナル36枚で、逆位置はありません
- カードは1つの質問につき1回だけ引きます。引き直しはしません（別の質問なら、新しい鑑定として引き直せます）
- 占いはエンターテインメントです。健康・法律・お金について断定的な判断はしませんし、怖がらせる言い方もしません
- 生年月日などの個人情報は、その回の鑑定だけに使います。スキルや共有資料に保存されることはありません
- ハウスや詳しいアスペクト（星同士の角度）は、この版では扱いません
