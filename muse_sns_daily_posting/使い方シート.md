# muse_sns_daily_posting 使い方シート

一言で言うと、作り置きの素材ストックから、InstagramとThreadsの投稿を1サイクル分準備し、最終確認と明示のOKがあったときだけ公開するスキルです。

## 聞き方に合わせて、説明のしかたが変わります

- **使い方だけ知りたい場合**：このシートで説明します（接続や設定の受け取りは行いません）
- **実際に使う場合**：初回だけ、先に設定を受け取ってから説明します

## 事前準備（初回だけ）

このスキルは、設定を持たない設計です。初回は、使う人の記録側から次の4つを受け取ります（スキル本体には書きません）。

- 投稿先のInstagramとThreadsのアカウント
- 素材の置き場所（Googleドライブのフォルダ）
- 投稿の順番と、進捗の記録の置き場所
- 準備したファイルの保存先フォルダ

2回目以降は、この受け取りは不要です。

## 普段の使い方

1. チャットで「muse_sns_daily_posting を使って」と言います
2. Museが両プラットフォームの実際の投稿済み状態を確認し、投稿順と進捗と照らして「次に投稿するペア」を決めます。今日分が公開済みなら、準備をせずに報告だけします
3. 素材を準備します（リールは100MB以内に圧縮し、カバー画像を用意。カルーセルは並びを揃えます）
4. キャプションは過去投稿の型で作ります。Threadsの文面は素材ファイルの原文をそのまま使います
5. 最終確認として、投稿先・内容・圧縮結果・カバー画像・キャプション全文・Threads文全文が提示されます
6. 「両方投稿／Instagramだけ／Threadsだけ／まだ投稿しない」から選びます。OKが出た分だけ公開され、URL2つと一緒に結果が報告され、進捗が記録されます

## 注意点

- 準備しただけでは公開されません。公開は必ず、最終確認と明示のOKの後だけです
- 投稿先は設定されたブランドアカウントのみです。個人アカウントには投稿しません
- Threadsの文は言い換え・短縮・装飾をしません。素材にない情報（ツール名・価格・収益など）は作りません
- 同じものを二重に準備・公開しません。「次」は計画ではなく、実際の公開状態から決めます
- スケジュール（何時に呼ぶか）は、このスキルの外の話です
