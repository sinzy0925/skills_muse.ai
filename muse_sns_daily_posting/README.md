# muse_sns_daily_posting（毎日のSNS投稿）

## 何をするスキルか

作り置きの素材ストックから、その日に投稿する分を取り出して、Instagram（リールまたはカルーセル）とThreads（文章）を1サイクル分、投稿するところまで進めるスキルです。

流れは「次に投稿するものを決める → 素材を準備する → キャプションを作る → 本人に最終確認を見せる → OKが出た分だけ公開する → 公開結果を確認して進捗を記録する」です。

## 使い方

チャットで「muse_sns_daily_posting を使って」と呼び出します。

始める前に、運用する人の記録側で次の設定を用意しておく必要があります（スキル本体には書きません）。

- 投稿先のInstagramとThreadsのアカウント
- 素材の置き場所（Googleドライブのフォルダ）
- 投稿の順番と進捗の記録
- 準備したファイルの保存先フォルダ

## 手順の要点

1. 両プラットフォームの実際の公開済み投稿を確認し、順番と進捗と照らして「次に投稿するペア」を決める（今日分が公開済みなら準備を省いて報告）
2. 素材をダウンロードし、リールは100MB以内に圧縮（1080x1920、字幕の読みやすさを確認）、カバー画像を用意する
3. 過去の投稿の型に沿ってキャプションを作る。Threadsの文章は素材ファイルの原文をそのまま使う
4. 投稿先・内容・キャプション・Threads文面を全部見せて最終確認を取る
5. OKが出た分だけ公開し、公開済み一覧で読み戻して確認、URLを報告して進捗を記録する

## 注意

- 公開は、必ず最終確認と本人の明示的なOKの後だけ。準備しただけでは公開しません
- 指定のブランドアカウントにだけ投稿し、個人アカウントには投稿しません
- Threadsの文章は言い換え・短縮・装飾をしません。素材に無い具体名（ツール名、価格、収益など）は作りません
- 同じものを二重に準備・公開しません。「次」は計画ではなく、実際の公開状態から決めます
- 429（レート制限）が出たら、その種類の投稿はその日は止めて、残りを報告します
- スケジュール（何時に呼ぶか）はこのスキルの外の話です。定期実行から呼ばれる想定で、スキル自体は時刻を持ちません
