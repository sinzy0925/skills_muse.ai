# muse_make_gijiroku_ai-output（AIアウトプット雑談会 議事録メーカー）

AIアウトプット雑談会の議事内容の文字起こしから、**短い議事録と超簡単議事録の2つ**を作り、確認後にDiscordの2か所へそれぞれ投稿するカスタムスキルです。投稿は内蔵ブラウザで、ユーザーが本人としてログインした状態で行います。

## できること

- 文字起こしから、短く簡素な新議事録を作成（話題と結論だけに絞り、次回予定で締める）
- 同じ内容から、定型フォーマットの超簡単議事録を作成
- 2つの投稿先へ、確認後に投稿

## 投稿先

どちらもSHIFT AI オンラインコミュニティ内です。WebhookやBotは使わず、内蔵ブラウザでDiscordにログインした本人のアカウントで投稿します。

| 成果物 | 投稿先 | 形式 |
| --- | --- | --- |
| 新議事録 | 🧑‍💻サークル内のスレッド『AIアウトプット雑談会』 | 添付画像と一緒に投稿 |
| 超簡単議事録 | ＃サークルリーダー交流内の『サークル開催報告』 | 文章のみ（画像は付けない） |

## 入力（4つそろわないと始めません）

以下の4つがそろっていない場合は、**下書きも投稿もせず、その場で止まります**。不足している項目を伝えて、ユーザーに補ってもらいます。

1. 今日の日付（開催日）
2. 来週の日付（次回予定）
3. 今日の参加人数
4. 新規参加人数

あわせて、議事内容の文字起こしと、議事録に添える集合写真などの画像1枚が必要です。

## 手順

1. **入力の確認**：上記4つがそろっているか確認。不足があればSTOPして不足分を聞く
2. **新議事録を作成**：文字起こしをもとに短く簡素にまとめる。`references/previous-minutes.md` は構成とトーンの参考のみで、前の議事録より大幅に短くする。文字起こしにない事実・名前・数字・話題は作らない
3. **超簡単議事録を作成**：下の定型フォーマットに同じ内容を入れる。「特に報告したい目新しい内容」は、本当に目新しい話題があったときだけ書き、なければ空欄または「なし」にする
4. **確認**：2つの文面をユーザーに見せ、OKまたは修正をもらう。OKが出るまで投稿しない
5. **投稿**：新議事録＋画像 → 『AIアウトプット雑談会』、超簡単議事録（文章のみ）→ 『サークル開催報告』の順に投稿し、両方の投稿が各投稿先の末尾に見えることを確認して報告する

### 超簡単議事録のフォーマット

```
━━━━━━━━━━━━━━━━━━━━
📝サークル開催報告
■サークル名：ＡＩアウトプット雑談会
■開催日： YYYY/MM/DD
■参加者数： ？？人
■新規参加者数：？人
■内容：
■感想：
■特に報告したい目新しい内容：
■次回予定：YYYY/MM/DD
━━━━━━━━━━━━━━━━━━━━
```

## 前提

- Discordへのログインはユーザーが内蔵ブラウザで事前に済ませておく（パスワードや認証コードをチャットで送る必要はありません）
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 下書きの確認と本人のOKなしに投稿しません
- Discordの1通あたりの文字数上限は2,000文字です。超える場合は文を切らずに連続投稿するか、ファイルとして添付します
- 画像は新議事録の投稿にだけ付け、超簡単議事録には付けません

## ファイル構成

```
muse_make_gijiroku_ai-output/
├── SKILL.md                  # スキル本体（手順）
├── skill.yaml                # メタ情報
└── references/
    └── previous-minutes.md   # 前回の議事録（構成とトーンの参考例）
```

## 使い方シート

同梱の「使い方シート.md」が、使い方の説明の正本です。使い方を聞かれたら、Museはまず一言説明をして、A（説明だけ聞きたい）／B（実際に使う）を尋ねます。Aではシートをそのまま提示し、Bでは必要な確認や準備をしてから、実際に使うものと一緒に説明します。人に渡すときも、シートごと渡してください。
