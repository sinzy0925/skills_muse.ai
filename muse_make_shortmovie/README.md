# muse_make_shortmovie（ナレーション付きショート動画作成）

テーマを渡すと、約60秒の縦型ショート動画を作るカスタムスキルです。先程の「スキル紹介動画」の作り方を、そのまま手順化したものです。

- **長さは最大**：生成クリップは1本約10秒で長さを選べないため、1回の依頼で作れる上限の6シーン × 約10秒 ＝ 約60秒で作ります
- **内容は事前確認**：シーン構成とナレーション原稿を全部見せて、OKが出るまで何も生成しません
- **音声はナレーション差し替え**：生成クリップの音はおかしくなりがちなので一切使わず、シーンごとの読み上げに差し替えます

## 使い方

作りたい動画のテーマを伝えます（例：「○○スキルを紹介する動画を作って」）。

| 項目 | 必須／任意 |
| --- | --- |
| テーマ／題材 | 必須（スキル名、商品、告知など） |
| 雰囲気 | 任意（既定は「クールでかっこいい感じ」） |
| 締めの文言 | 任意（エンドカードの文言。無ければ確認時に提案） |

## 手順

1. **入力の確認**：テーマが無ければ質問します（推測で埋めません）
2. **構成づくり**：6シーン分の「映像イメージ」と「ナレーション原稿（1シーン40〜60字目安）」を作ります
3. **事前確認**：構成と原稿を全部見せて、OKをもらいます（ここが必須の関門です）
4. **映像生成**：シーンごとにクリップを生成します（縦型9:16、共通のスタイル指定で世界観を統一）
5. **ナレーション生成と実測**：同じ声で6本読み上げを作り、全部が10秒以内に収まることを実測します。収まらない場合は、テンポの速い声に変えて全シーンを作り直します（声は全編統一）
6. **合成**：各クリップの音声をナレーションに差し替え（無音で10秒にそろえる）、6シーンを連結します
7. **検証と受け渡し**：総尺（約60秒）と、全シーンに音声が入っていることを確認してから、チャットに添付して渡します

## 続きもの（60秒を超える物語）

- 物語は6シーン（約60秒）ごとに「パート」へ分け、パートごとに通常の手順で作ります。全部のパートができたら、順番に連結して1本にします（2パートで約120秒）
- 合計が60秒を超える場合は、事前確認で投稿先も聞き、その投稿先の長さ上限に収まるか確認します（例：YouTube ShortsとInstagramリールは3分まで、Instagramストーリーズは60秒まで、Xの無料アカウントは140秒まで）。超える場合は、生成前にパート数の調整を提案します
- キャラクターが出る物語では、パート1の前に「キャラシート（基準画像1枚）」と「キャラクター設定の固定文」を作り、事前確認で承認をもらって保管します。全パート・全シーンの生成で、基準画像を入力として渡し、設定文をそのまま使い回します。声も全編で統一します
- 生成AIの性質上、キャラクターが100%同一になる保証はありません。基準画像＋固定文で「同じキャラ」に寄せる設計で、細部が少しブレることはあります（この点は確認のときに伝えます）

## 前提

- 動画生成は1回の依頼につき最大6クリップまで、という上限がこのスキルの「最大60秒」の根拠です
- 連結には ffmpeg を使います
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 生成クリップ内の文字は装飾的に崩れることがあります。正確な情報はナレーションで伝える設計です（名前や価格など正確さが要る文字は、確認のときにその旨を伝えます）
- このスキルは動画を作るまでです。InstagramやYouTubeへの投稿は、別途確認を挟む別の作業です
- 原稿を勝手に短くしたり、承認された内容を変えたりはしません。変更が必要なときは先に伝えます

## 由来

2026-11-15、スキル紹介のショート動画を実際に作ったときの手順と教訓（生成音声がおかしかったのでナレーションに差し替えた／声によって読み上げ速度が大きく違い、10秒に収まるかの実測が要る）を、本人の指定（「動画は最大の長さで作る」「内容は事前確認する」）と一緒にスキル化したものです。

## 使い方シート

同梱の「使い方シート.md」が、使い方の説明の正本です。使い方を聞かれたら、Museはまず一言説明をして、A（説明だけ聞きたい）／B（実際に使う）を尋ねます。Aではシートをそのまま提示し、Bでは必要な確認や準備をしてから、実際に使うものと一緒に説明します。人に渡すときも、シートごと渡してください。
