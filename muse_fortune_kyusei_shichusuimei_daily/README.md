# muse_fortune_kyusei_shichusuimei_daily（九星気学 × 四柱推命 デイリー鑑定）

九星気学と四柱推命を役割分担させて束ねる、**デイリー（今日の運勢）専用**のカスタムスキルです。このスキルには抽選が無く、両方とも計算で出すため、同じ人の同じ日は必ず同じ結果になります。

- **四柱推命** ＝ 日の流れ：本人の日主と、その日の干支（特に日柱）の関係
- **九星気学** ＝ 年・月の流れ：本人の本命星・月命星と、今年の九星・今月の九星（月盤中宮）の関係

鑑定文は決まった5部構成（今日のデータ→今日の運気→ラッキーアクション→気をつけること→締めの一言）で、短め（400〜500字前後）が既定です。姉妹スキル `muse_fortune_shichusuimei_tarot`（四柱推命 × タロット）、`muse_fortune_kyusei_runes`（九星気学 × ルーン）と同じ設計思想です。

## 使い方

生年月日を伝えて「今日の運勢」と言います。

| 項目 | 必須／任意 |
| --- | --- |
| 生年月日 | 必須 |
| 出生時刻 | 任意（命式の時柱に使うだけ。無くても日運は出ます） |
| 対象日 | 任意（既定は今日。明日・明後日も指定できます） |
| 気になること | 任意（1行。ラッキーアクションと注意点がそれ寄りになります） |

## 手順

1. **入力の確認**：不足があればまとめて質問（推測で埋めません）
2. **材料の計算**：同梱の計算ヘルパーで命式・本命星・月命星と、対象日の干支・今年と今月の九星・五行の関係（相生／相剋／比和／漏気／制気）を出す。初回は既知のサンプル（四柱推命5件、九星3件、月盤2件、五行の関係5件）で検算し、通らなければ鑑定を始めません
3. **デイリー鑑定の作成**：5部構成で、2つの計算結果を束ねます
4. **提示**：同じ日の再計算は同じ結果になります（抽選ではないため）

## 前提

- 計算に Python ライブラリ **sxtwl** を使います（未導入なら `pip install sxtwl`）。計算できない環境では、暗算に切り替えず停止して報告します
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます

## 注意

- 占いはエンターテインメントとして提示します。健康・法律・お金について断定的な判断はせず、怖がらせる表現は使いません
- 生年月日などの個人情報はその回の鑑定だけに使い、スキルや共有物に保存しません
- 日盤（日単位の九星盤）と方位（吉方位）は v1 の範囲外です。日の流れは四柱推命の日柱で見ます
- 五行バランスは v1 の簡略化として、天干と地支の本気だけで数えます（蔵干は数えません）。大運も範囲外です

## 由来

ユーザーの合体占いの設計（2026-11-17）をもとに作成。役割分担（四柱推命＝日の流れ、九星気学＝年・月の流れ）、両方とも計算で抽選を入れないこと、計算の検算を必須とすること、日盤・方位を v1 に入れないことは、本人の確認済みの決定です。
