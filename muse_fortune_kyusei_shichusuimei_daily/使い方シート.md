# muse_fortune_kyusei_shichusuimei_daily 使い方シート

一言で言うと、生年月日から四柱推命と九星気学の両方で計算して、今日の運勢を短く出すスキルです。

## 聞き方に合わせて、説明のしかたが変わります

- **使い方だけ知りたい場合**：このシートで説明します（生年月日は集めず、鑑定もしません）
- **実際に使う場合**：入力項目（生年月日・出生時刻）を確認してから、その項目がどう使われるかと一緒に説明します

## 事前準備（最初に1回だけ）

- 初回の鑑定の前に、計算が正しいかを既知のサンプルで自動チェックします（検算）。チェックを通らない場合は、鑑定を始めずにその旨が報告されます
- 準備として何かをインストールしたり、登録したりする必要はありません

## 普段の使い方

1. 生年月日を伝えて「今日の運勢」と言います（出生時刻が分かれば、それも伝えます）
2. 不足している項目があれば、まとめて質問されます。推測で埋めることはしません
3. 命式・本命星と、今日の干支・今月の九星などの材料が計算されます
4. 今日の運勢が出ます
   - 今日のデータ → 今日の運気 → ラッキーアクション → 気をつけること → 締めの一言
   - 短め（400〜500字前後）が既定です。「明日の運勢」のように日を指定することもできます
   - 気になること（例：仕事の会議）を1行添えると、内容がそれ寄りになります

## 注意点

- このスキルには抽選がありません。計算だけなので、同じ人の同じ日は何度見ても同じ結果です
- 出生時刻が分からなくても大丈夫です（命式の一部が簡易計算になるだけで、日運は出ます）
- 方位（吉方位）や日盤は、この版では扱いません。日の流れは四柱推命で、年と月の流れは九星気学で見ます
- 占いはエンターテインメントです。健康・法律・お金について断定的な判断はしませんし、怖がらせる言い方もしません
- 生年月日などの個人情報は、その回の鑑定だけに使います。スキルや共有資料に保存されることはありません
