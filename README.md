# Muse カスタムスキル集

Muse（MetaのパーソナルAIエージェント）で使う、カスタムスキルの置き場です。
1フォルダ＝1スキルになっていて、フォルダの中に手順書（SKILL.md）と、人のための説明（README.md）が入っています。

## このリポジトリの使い方

初回のインストールは、専用スキル `muse_install_app` が一括でやります。

1. このリポジトリのZIPをダウンロードして、展開します。
   https://github.com/sinzy0925/skills_muse.ai/archive/refs/heads/main.zip
2. あなたのmuse.aiのチャットで、展開した中にあるスキル `muse_install_app` を実行するよう伝えてください。
3. インストール計画が提示されるので、内容を確認してOKを出すと、スキル全部の登録、「常時参照して欲しいメモ」の登録、スペース7つ（スキルランチャー、住民税非課税シミュレーター、トークンメーター、システムメーター、タスクメーター、スペースランチャー、占いランチャー）の作成まで進みます。公開リンクの共有は行いません。

※ ZIPの展開で日本語のファイル名が文字化けした場合は、UTF-8対応の方法で展開し直してください。

登録済みの一式を最新に更新したいときは、チャットでスキル `muse_skills_space_update` を実行してください（差分を見せてから更新します。ローカルにだけあるスキルは消しません）。

## スキルランチャー

リポジトリの直下には `スキルランチャー.html` があります。全スキルをカテゴリ別に並べた一覧ページで、ブラウザで開くと、各スキルの一言説明と使い方（簡易説明／詳細説明）、実行用の指示文のコピーが使えます。

初回インストール（`muse_install_app`）で、このHTMLと同じ内容のスペース（スキルランチャー）があなたのmuse.aiのサイドバーに作られます（作り直しになるので、見た目の細部が元と少し違う場合があります）。

## 住民税非課税シミュレーター

リポジトリの直下には `住民税非課税シミュレーター.html` もあります。年金収入などから住民税が非課税になるかどうかを概算する単一HTMLのアプリで、ブラウザでそのまま開いても使えます（令和8年度前提の概算です）。

初回インストール（`muse_install_app`）で、このHTMLと同じ内容のスペースがあなたのmuse.aiのサイドバーに作られます（作り直しになるので、見た目の細部が元と少し違う場合があります）。

判定結果の下にある「結果をコピー（AI確認用）」ボタンの文章をチャットに貼ると、スキル `muse_check_resident_tax_simulation` が呼ばれ、検算・見落としチェック・最新情報の確認までしたレポートが返ります。シミュレーターとスキルはセットで使う設計です。

## トークンメーター

リポジトリの直下には `トークンメーター.md` もあります。Museの週次トークン使用率をゲージで見える化するアプリ型スペース（データを保存するタイプ）です。

このスペースはデータを保存する仕組みを持つため、HTMLファイルのコピーでは配布できません。その代わり、`トークンメーター.md` が「再現のための仕様書」になっています。そのファイルをあなたのMuseに見せて、自分の言葉で作りたいと伝えると、確認しながら同じアプリがあなたの環境に作られます。途中で、使用記録の読み取りと定期ジョブの作成について確認が入ります。表示される数値は、作った人自身の使用状況のものになります（公式の使用率はMuseのサブスクリプション情報から読み、タスク別の内訳は割合だけを表示します）。

なお、初回インストール（`muse_install_app`）でも、この仕様書をもとにスペースが作られます。

## システムメーター

リポジトリの直下には `システムメーター.md` もあります。Museが動いている環境（サーバー）の状態――ディスクの残量、フォルダごとの容量、メモリ、CPU、OS――をゲージやバーで見える化するアプリ型スペース（データを保存するタイプ）です。

このスペースはデータを保存する仕組みを持つため、HTMLファイルのコピーでは配布できません。その代わり、`システムメーター.md` が「再現のための仕様書」になっています。そのファイルをあなたのMuseに見せて、自分の言葉で作りたいと伝えると、確認しながら同じアプリがあなたの環境に作られます。途中で、環境情報の読み取りと定期ジョブの作成について確認が入ります。表示される数値は、作った人自身の環境のものになります（測れるのはMuseの環境の状態で、あなたのPCの状態ではありません）。

なお、初回インストール（`muse_install_app`）でも、この仕様書をもとにスペースが作られます。

## タスクメーター

リポジトリの直下には `タスクメーター.md` もあります。Museに登録した定時タスク（声かけリマインドや定期チェックなど）の状態――次に動くタスク、予定、次回時刻、前回の実行結果、有効かどうか――をまとめて見える化するアプリ型スペース（データを保存するタイプ）です。

このスペースはデータを保存する仕組みを持つため、HTMLファイルのコピーでは配布できません。その代わり、`タスクメーター.md` が「再現のための仕様書」になっています。そのファイルをあなたのMuseに見せて、自分の言葉で作りたいと伝えると、確認しながら同じアプリがあなたの環境に作られます。途中で、定時タスク情報の読み取りと定期ジョブの作成について確認が入ります。表示されるのは、作った人自身の定時タスクの状態です（タスクの作成・変更・停止はこのアプリからは行いません）。

なお、初回インストール（`muse_install_app`）でも、この仕様書をもとにスペースが作られます。

## スペースランチャー

リポジトリの直下には `スペースランチャー.md` もあります。自分のスペースをタイルで並べたホーム画面のような静的スペース（データを保存しないタイプ）です。

このスペースは、持ち主自身のスペースへのリンク集なので、HTMLファイルのコピーでは配布できません。その代わり、`スペースランチャー.md` が「再現のための仕様書」になっています。初回インストール（`muse_install_app`）でも、この仕様書をもとにスペースが作られます。

タイルのリンクは相対パスの通常のアンカーで、iPhoneアプリではタップでそのまま開けます。PC（Web版）では、ページの中から別スペースへ移る動きがシェル側に止められるため、タイルからは開けません（PCではスペースはサイドバーから開きます。2026-11-17に作者の環境で実測済み）。

## 占いランチャー

占いスキル専用の静的スペース（データを保存しないタイプ）で、サイドバーに置かれます。合体占い5本（四柱推命×タロット、九星気学×ルーン、数秘術×タロット、西洋占星術×オラクル、九星気学×四柱推命デイリー）のカードと、「全部まとめて」「占いの定期実行を設定」のカードが並びます。

占いスキルはスキルランチャーには登録せず、このランチャーにまとめています。ランチャーは「選ぶだけ」の画面で、入力欄はありません。カードを選ぶと実行用の文が用意され、実際の鑑定はチャットで生年月日や相談テーマを伝えて行います。

このスペースには、リポジトリ直下に元になるHTMLや仕様書ファイルがありません。再現のためのアウトラインは、スキル `muse_install_app` のSKILL.mdの中に収めてあります。初回インストール（`muse_install_app`）で、このアウトラインをもとにスペースが作られます。

## 手作業で入れる場合

1. このリポジトリのZIPをダウンロードして、展開します。
2. 使いたいスキルのフォルダを、Museのカスタムスキル置き場（`custom-skills/`）に入れます。
3. `常時参照して欲しいメモ.md` の内容を、常時参照するメモに保存します。
4. Museのチャットで、スキル名で呼び出して使います（例：「muse_up_youtube_from_google_drive_mp4 を使って」）。

各スキルの詳しい使い方・前提・注意は、それぞれのフォルダ内の README.md を見てください。

## ルールのメモも入っています

リポジトリの直下には `常時参照して欲しいメモ.md` があります。これはスキルではなく、Museにいつも守ってほしいルール（投稿前に下書き確認する、固まったら見切って報告する、など）をまとめたメモです。

登録のしかたは、初回インストール（`muse_install_app`）に含まれています。

## 前提

- Museのアカウントが必要です。
- スキルによっては、Googleアカウントの連携や、Museの内蔵ブラウザでのログイン（YouTube Studio、Discordなど）が必要です。
- 投稿や公開のような外向きの操作は、いきなり実行せず、下書きを見せて本人のOKをもらってから行う作りになっています。

## 中身の約束事

- スキルを作るときは、SKILL.md と skill.yaml に加えて、人間向けの README.md を必ず付けます。
- スクショ系スキルのスライドでは、元の画像自体は編集しません。個人情報のマスクや注釈は、スライド上の図形として載せます。
