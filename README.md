# Muse カスタムスキル集

Muse（MetaのパーソナルAIエージェント）で使う、カスタムスキルの置き場です。
1フォルダ＝1スキルになっていて、フォルダの中に手順書（SKILL.md）と、人のための説明（README.md）が入っています。

## このリポジトリの使い方

あなたのmuse.aiのチャット画面に、下の指示文をそのまま貼ってください。スキルと「常時参照して欲しいメモ」の登録が完了します（ZIPのダウンロードと展開はmuse.aiがやります）。

```
https://github.com/sinzy0925/skills_muse.ai/archive/refs/heads/main.zip
1. 上記のZIPをダウンロードして、展開する。
2. スキルはカスタムスキルに登録する。
3. スキルランチャー.htmlと同じ内容のスペースを作って、サイドバーに置いて（アイコンはロケットにして）
4. 住民税非課税シミュレーター.htmlと同じ内容のスペースを作って、サイドバーに置いて （アイコンはノートにして）
5. 常時参照して欲しいメモ.md は、あなたが常に参照するメモに登録する。
```

※ ZIPの展開で日本語のファイル名が文字化けした場合は、UTF-8対応の方法で展開し直してください。

登録済みの一式を最新に更新したいときは、チャットでスキル `muse_skills_space_update` を実行してください（差分を見せてから更新します。ローカルにだけあるスキルは消しません）。

## スキルランチャー

リポジトリの直下には `スキルランチャー.html` があります。全スキルをカテゴリ別に並べた一覧ページで、ブラウザで開くと、各スキルの一言説明と使い方（簡易説明／詳細説明）、実行用の指示文のコピーが使えます。

冒頭の指示文の3番まで実行すると、このHTMLと同じ内容のスペース（スキルランチャー）があなたのmuse.aiのサイドバーに作られます（作り直しになるので、見た目の細部が元と少し違う場合があります）。

## 住民税非課税シミュレーター

リポジトリの直下には `住民税非課税シミュレーター.html` もあります。年金収入などから住民税が非課税になるかどうかを概算する単一HTMLのアプリで、ブラウザでそのまま開いても使えます（令和8年度前提の概算です）。

冒頭の指示文の4番まで実行すると、このHTMLと同じ内容のスペースがあなたのmuse.aiのサイドバーに作られます（作り直しになるので、見た目の細部が元と少し違う場合があります）。

判定結果の下にある「結果をコピー（AI確認用）」ボタンの文章をチャットに貼ると、スキル `muse_check_resident_tax_simulation` が呼ばれ、検算・見落としチェック・最新情報の確認までしたレポートが返ります。シミュレーターとスキルはセットで使う設計です。

## トークンメーター

リポジトリの直下には `トークンメーター.md` もあります。Museの週次トークン使用率をゲージで見える化するアプリ型スペース（データを保存するタイプ）です。

このスペースはデータを保存する仕組みを持つため、HTMLファイルのコピーでは配布できません。その代わり、`トークンメーター.md` が「再現手順書」になっています。そのファイルをあなたのMuseに見せて「この手順書のとおりに作って」と伝えると、同じアプリがあなたの環境に作られます。表示される数値は、作った人自身の使用状況のものになります（公式の使用率はMuseのサブスクリプション情報から読み、タスク別の内訳は割合だけを表示します）。

なお、冒頭の指示文（最新化の5ステップ）には含まれていないので、欲しい人だけ個別に作る形です。

## システムメーター

リポジトリの直下には `システムメーター.md` もあります。Museが動いている環境（サーバー）の状態――ディスクの残量、フォルダごとの容量、メモリ、CPU、OS――をゲージやバーで見える化するアプリ型スペース（データを保存するタイプ）です。

このスペースはデータを保存する仕組みを持つため、HTMLファイルのコピーでは配布できません。その代わり、`システムメーター.md` が「再現手順書」になっています。そのファイルをあなたのMuseに見せて「この手順書のとおりに作って」と伝えると、同じアプリがあなたの環境に作られます。表示される数値は、作った人自身の環境のものになります（測れるのはMuseの環境の状態で、あなたのPCの状態ではありません）。

なお、冒頭の指示文（最新化の5ステップ）には含まれていないので、欲しい人だけ個別に作る形です。

## 手作業で入れる場合

1. このリポジトリのZIPをダウンロードして、展開します。
2. 使いたいスキルのフォルダを、Museのカスタムスキル置き場（`custom-skills/`）に入れます。
3. `常時参照して欲しいメモ.md` の内容を、常時参照するメモに保存します。
4. Museのチャットで、スキル名で呼び出して使います（例：「muse_up_youtube_from_google_drive_mp4 を使って」）。

各スキルの詳しい使い方・前提・注意は、それぞれのフォルダ内の README.md を見てください。

## ルールのメモも入っています

リポジトリの直下には `常時参照して欲しいメモ.md` があります。これはスキルではなく、Museにいつも守ってほしいルール（投稿前に下書き確認する、固まったら見切って報告する、など）をまとめたメモです。

登録のしかたは、冒頭の「このリポジトリの使い方」の指示文に含まれています。

## 前提

- Museのアカウントが必要です。
- スキルによっては、Googleアカウントの連携や、Museの内蔵ブラウザでのログイン（YouTube Studio、Discordなど）が必要です。
- 投稿や公開のような外向きの操作は、いきなり実行せず、下書きを見せて本人のOKをもらってから行う作りになっています。

## 中身の約束事

- スキルを作るときは、SKILL.md と skill.yaml に加えて、人間向けの README.md を必ず付けます。
- スクショ系スキルのスライドでは、元の画像自体は編集しません。個人情報のマスクや注釈は、スライド上の図形として載せます。
