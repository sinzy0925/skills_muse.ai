# muse_receipt_pdf_to_sheets（領収書PDFをスプレッドシート台帳へ）

## 何をするスキルか

確定申告のために、Googleドライブの「領収書整理_実行前」フォルダに入れた領収書PDFや画像を読み取り、Googleスプレッドシートの経費台帳に整理して、処理済みのファイルを「領収書整理_実行後」フォルダへ移すスキルです。

流れは「接続確認 → 実行前フォルダの領収書を読み取り → 重複統合・見本除外 → 台帳へ追記 → 読み戻して検証 → 要確認点を報告 → 実行後フォルダへ移動 → 移動結果を検証」です。

## 使い方

チャットで「muse_receipt_pdf_to_sheets を使って」と呼び出すか、「実行前に領収書を入れたので整理して」のように指示します。

同梱の「使い方シート.md」が、使い方の説明の正本です。使い方を聞かれたら、Museは要約や言い換えをせず、このシートをそのまま提示します。人に渡すときも、このシートごと渡してください。

## 事前に必要なもの

- GoogleドライブとGoogleスプレッドシートの接続（未接続の場合、スキルが接続リンクを案内します）
- ドライブのフォルダ「領収書整理_実行前」「領収書整理_実行後」（なければ初回に作成します）
- 台帳のスプレッドシート（なければ初回に下記の形式で作成します）

このスキル自体には、フォルダID・スプレッドシートID・URL・個人情報を一切書いていません。すべて名前で探すので、そのまま他人に共有できます。実際に解決したIDは、使う人それぞれの記録側（メモリなど）に保持してください。

## 台帳の形式

シートは「領収書一覧」「集計」「項目の説明」の3枚です。「領収書一覧」は15項目：

No. / 日付 / 支払先・発行者 / 内容（品目・但し書き）/ 勘定科目 / 金額（税込）/ 税率区分 / 消費税額 / 税抜金額（自動計算）/ 支払方法 / インボイス登録番号 / 事業割合（%) / 経費計上額（自動計算）/ 証憑ファイル / 備考・要確認

「集計」には勘定科目別・税率区分別・月別の合計を用意します。

## 注意

- 読み取れない文字や金額は推測しません。「要確認」として備考と報告に残します
- 同じ領収書のPDFと写真は重複として1件に統合し、領収書の見本・テンプレート画像は台帳に入れません
- 手書き領収書で発行者名・登録番号・税額の記載がない場合は、その旨を必ず報告します
- 勘定科目は提案であり、事業用か私用か判断できないものには（仮）を付けます
- ファイルの移動は、台帳への記入と読み戻し確認が終わってから行い、移動後に両フォルダを検証します
