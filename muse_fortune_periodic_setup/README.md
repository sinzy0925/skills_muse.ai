# muse_fortune_periodic_setup（占い定期実行セットアップ）

合体占い5本の **定期実行を設定・変更・停止するためだけ** のカスタムスキルです。このスキル自体は占いをしません。占いの実行は、各曜日に割り当てられた占いスキルが担当します。

- **対象の占い**：`muse_fortune_shichusuimei_tarot`（四柱推命 × タロット）、`muse_fortune_kyusei_runes`（九星気学 × ルーン）、`muse_fortune_numerology_tarot`（数秘術 × タロット）、`muse_fortune_astrology_oracle`（西洋占星術 × オラクルカード）、`muse_fortune_kyusei_shichusuimei_daily`（九星気学 × 四柱推命・デイリー）
- **このスキルの仕事**：設定項目を提案としてまとめて提示 → 回答をもらう → 内容を確認してOKをもらう → 定期実行を登録する。変更・停止も同じ定期実行を更新・削除して行います

占いランチャーからは、このスキルを呼び出すだけにします（ランチャー側に生年月日などの入力欄は置きません。静的ページでは入力が保持できないため、設定はチャットで完結させる設計です）。

## 使い方

「占いを定期実行したい」と伝えます。すると、スキルが次の設定項目をまとめて提案します。

| 項目 | 内容 |
| --- | --- |
| 実行パターン | 標準は曜日ローテーション（月＝西洋占星術×オラクル、火＝九星気学×ルーン、水＝数秘術×タロット、木＝四柱推命×タロット、金＝九星×四柱デイリー、土＝全部まとめて、日＝九星×四柱デイリー）。テーマは「今日の全体運」で固定が標準。1本固定や曜日差し替えも可能 |
| 実行タイミング | 毎日・何時か（既定候補 8:00） |
| イメージ化 | 欲しいかどうか。聞くときに「画像を毎日生成するとトークンを多めに消費しますよ！」という注意喚起が必ず出ます。欲しい場合は1日1枚だけ、生成は毎日の実行を担当するClaudeが行います。雰囲気はクール・かっこいい／かわいい／静か |
| 必要情報 | 生年月日（必須）、出生時刻・出生地（任意。不明なら該当する占いは簡易鑑定） |
| 届け先 | 設定を行ったチャット |

## 手順

1. **提案と回答**：上記の設定項目をまとめて提示し、不足分は一度に質問（推測で埋めません）
2. **確認**：登録前に設定内容のまとめを見せて、OKが出るまで登録しません
3. **既存チェック**：すでに占いの定期実行がある場合は二重登録せず、その定期実行をこのスキルの管理下に置いて更新します
4. **登録**：毎日指定時刻の定期実行を登録。毎回の実行では、その曜日の占いスキルの手順（計算ヘルパーの検算を通らなければ鑑定しない、抽選は1質問1回だけ、など）に従います
5. **報告**：タスクメーターの再計測も行い、次回実行（日時・曜日・占い名）を報告します
6. **変更・停止**：変更は同じ定期実行を更新、停止は削除（または無効化）して報告します

## 前提

- 占いスキル5本が登録されていることが前提です（このスキルは占い本体を持ちません）
- このスキルは常時読み込みオフ（`include_in_prompt: false`）のため、使うときは名前で呼びます
- スキルランチャーには登録しません（占いランチャー用です）

## 注意

- 占いはエンターテインメントとして提示します。各回の鑑定では、健康・法律・お金について断定的な判断はしません
- 生年月日などの個人情報は、設定した本人の定期実行の中だけに持たせます。スキル本体・ランチャー・共有資料には残しません。このスキル自体にも、特定の生年月日・チャットやジョブの固有ID・個人名は含まれていません
- 定期実行からLINEへの送信はしません（連携は保留中）。SNSへの投稿も、本人の承認なしにはしません
- 土曜の「全部まとめて」は1週間でいちばん重い実行です。消費が気になる場合は、イメージ化を土曜だけにする等の軽い代替案を提示しますが、勝手に変えません

## 由来

ユーザーの設計（2026-11-17）をもとに作成。占いランチャーは占いを選ぶだけに残し、定期実行の設定はスキル側が提案を出してユーザーに答えてもらう形にすること、曜日ローテーションと「今日の全体運」固定を標準提案とすること、イメージ化は1日1枚で注意喚起を必ず出すこと、すでに動いている定期実行は新規作成せずスキルの管理下に置くことは、本人の確認済みの決定です。

## 使い方シート

同梱の「使い方シート.md」が、使い方の説明の正本です。使い方を聞かれたら、Museはまず一言説明をして、A（説明だけ聞きたい）／B（実際に使う）を尋ねます。Aではシートをそのまま提示し、Bでは必要な確認や準備をしてから、実際に使うものと一緒に説明します。人に渡すときも、シートごと渡してください。
